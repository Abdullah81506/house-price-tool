# Is this Lahore listing priced like its neighbours?

Compares any Zameen.com property listing against real listings of similar size
in the same area, using 13,203 scraped Lahore listings.

Built with FastAPI and XGBoost. Trained on asking prices — Pakistan has no
public record of sale prices.
